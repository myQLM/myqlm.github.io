.. _windows:

myQLM Installation on Windows
-----------------------------
MyQLM on Windows supports two environments: Python.org and Conda.

Installing myQLM on Windows requires `Visual C++ v14 Redistributable <https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170#latest-supported-redistributable-version>`_ for qdldl to work.
