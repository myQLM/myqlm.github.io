qat.core.variables.conjugate
============================

.. function:: qat.core.variables.conjugate(number)

    Computes the conjugate of a complex number.

    .. run-block:: python

        from qat.core.variables import conjugate

        print(conjugate(1 + 1j))

    :param number: complex number
    :type angle: :class:`~qat.core.Variable` or :class:`~qat.core.variables.ArithExpression` or number

    :return: conjugate
    :rtype: :class:`~qat.core.variables.ArithExpression` or number
