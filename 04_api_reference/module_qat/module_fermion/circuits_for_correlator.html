qat.fermion.correlators.circuits_for_correlator

qat.fermion.correlators.circuits_for_correlator(op_a: Observable, op_b: Observable, t_a: float, t_b: float, time_evol_qroutine, state_prep: QRoutine | None = None, real_part_only: bool = False) → Tuple[List[Tuple[complex, Circuit]], complex]

Produce a list of circuits with complex coefficients that can be used to compute a correlation function

\[\langle\psi_0 | A(t_a) B(t_b) |\psi_0\rangle\]

If time_evol_qroutine yields a quantum channel \(E\), this corresponds to computing

\[\mathrm{Tr}[A E_{t_a - t_b}[B E_{t_b}[\psi_0]]]\]

for \(t_a \ge t_b\), and

\[\mathrm{Tr}[B^\dagger E_{t_b - t_a}[A^\dagger E_{t_a}[\psi_0]]]^*\]

for \(t_a \le t_b\). \(\psi_0\) is the initial state density matrix.

The correlation functions are obtained through a Hadamard test, whose ancilla is the first qubit. The result is therefore the expectation of Z on the first qubit for each circuit, multiplied by the complex coefficient and summed over circuits. Finally, an offset must be added.

Parameters:

  • op_a (Observable) – operator \(A\)

  • op_b (Observable) – operator \(B\)

  • t_a (float) – time \(t_a\)

  • t_b (float) – time \(t_b\)

  • time_evol_qroutine (Callable float -> QRoutine) – Factory for time evolution Qroutine. The float parameter represents time.

  • state_prep (QRoutine, optional) – circuit to prepare \(|\psi_0\rangle\)

  • real_part_only (bool, optional) – True to compute only the real part of the correlation function, using half the number of circuits. Default to False.

Returns:

a list of circuits with associated complex coefficient. complex: offset

Return type:

list<pair<complex, Circuit>>
