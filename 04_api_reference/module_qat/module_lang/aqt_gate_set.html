qat.lang.vendors.aqt_gate_set

qat.lang.vendors.aqt_gate_set(target='marmot')

Generate a GateSet object corresponding to the gate set of AQT.

The AQT Marmot gate set is composed of:

Gate name

Notation

Arity

Definition

Z rotation

\(RZ(\theta)\)

1

\(\forall \theta \in\rm I\!R: \begin{vmatrix} e^{-i\theta/2} & 0 \\ 0 & e^{i\theta/2} \\ \end{vmatrix}\)

PRX gate

\(PRX(\theta, \phi)\)

1

\(\forall \theta, \phi \in\rm I\!R^2: \begin{vmatrix}cos(\theta/2) & -i \cdot e^{-i \phi} \cdot sin(\theta/2) \\ -i \cdot e^{i \phi} \cdot sin(\theta/2) & cos(\theta/2) \\ \end{vmatrix}\)

RXX gate

\(RXX(\theta)\)

2

\(\forall \theta \in\rm I\!R: \begin{vmatrix} cos(\theta/2) & 0 & 0 & -i \cdot sin(\theta/2) \\ 0 & cos(\theta/2) & -i \cdot sin(\theta/2) & 0 \\ 0 & -i \cdot sin(\theta/2) & cos(\theta/2) & 0 \\ -i \cdot sin(\theta/2) & 0 & 0 & cos(\theta/2) \\ \end{vmatrix}`\)

 
from qat.lang.vendors import aqt_gate_set

for gate_name in aqt_gate_set(target="marmot"):
    print(gate_name)

RZ
PRX
RXX
Parameters:

target (str) – The target AQT processor family (marmot). Defaults to marmot.

Returns:

Gate set of the selected AQT processor family

Return type:

GateSet
